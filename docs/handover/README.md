# Handover documents

Dan, this folder holds the M5 handover documents for the tap to story system. They are here so you can read them in your own repository before the knowledge transfer session.

## What is in the folder

- The handover package: the index, `00-index.md`, and the seven documents numbered 01 to 07, plus `licences.json`.
- Five documents the package refers to by title: "Decision log", "Operations runbook", "M4 status", "M5 status" and "The deployed development environment".

## Reading order

1. Start with the index, `00-index.md`. It lists the seven documents and says what each one answers.
2. Then follow the reading order the index gives: "Orientation for a new developer" first, then "Architecture and the reasoning behind it", sections 1 to 4, then whichever document fits the job in front of you.
3. Open the other five documents when a document points you to them by title.

## How to read the dates

The documents are dated narratives. Most of the text describes the project on the date written beside it, and later corrections were added on top instead of rewriting what came before.

The index opens with a current state block. Where anything else in the folder disagrees with that block, the block wins.

A short note dated Wednesday 21 October 2026 now sits at the top of that block. It is the latest position.

## Two things to know

The documents refer to each other by title and section number, not by file name, so every reference still works here.

The decision log in this folder carries only the engineering entries these documents cite. The other entries are marked as withheld and keep their numbers, so references to them still line up.

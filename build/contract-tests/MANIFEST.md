## Design constraint

Minimal dependencies, chosen so this suite can be adopted into the client `nfc-development`
repository without dragging a test framework and a plugin ecosystem with it.

Three runtime packages. No test framework, no HTTP client library, no mock server library, no
assertion library, no OpenAPI tooling beyond a YAML parser and a JSON Schema validator. The test
runner is `node:test`, the assertions are `node:assert`, the HTTP client is the global `fetch`, and
the stub server is `node:http`, all built into Node.

## Licence obligations, plainly

MIT, ISC, BSD-3-Clause and Apache-2.0 are all permissive. The obligations are the same in
substance: keep the copyright notice and the licence text with any redistribution. None of them is
copyleft, none requires disclosing the source of the work that uses them, and none restricts
commercial use.

`npm install` writes the licence text of every package into `node_modules`, which satisfies the
notice requirement for a repository checkout. If any part of this suite is redistributed as a
built artifact rather than as source, the licence files for the packages above travel with it.
